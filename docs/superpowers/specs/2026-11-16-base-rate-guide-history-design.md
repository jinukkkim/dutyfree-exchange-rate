# 기준환율 변경 이력 — 가이드 추가

사용자가 승인한 범위는 한국어 `/guide`의 기존 기준환율 설명 아래에 확인된 변경 이력을 공개하는 것이다. 홈의 오늘·내일 환율, 구매금액 계산기와 과거 날짜 조회는 이번 범위에 포함하지 않는다.

## 접근

홈에 표를 넣으면 결제 적용환율과 혼동하기 쉽다. 별도 페이지는 이번 규모에 필요하지 않으므로 기존 가이드에 작은 표를 추가한다. 기존 Pretendard·흰 바탕·슬레이트 본문 스타일을 유지한다.

`data/base_rates.csv`와 `data/meta.json`을 재사용한다. 각 면세점의 직전 기록을 기준으로 변경 전후 값을 구하고, 적용일·변경 값·확정 여부·출처가 같은 면세점은 한 행으로 합쳐 최신순으로 표시한다. 최초 기록은 이전 값을 추정하지 않는다. 날짜·면세점, 변경 값, 기사 링크의 세 열로 모바일 폭에 맞춘다.

제목은 ‘면세점 기준환율(국산품용) 변경 이력’. 마지막 확인일과 수동 기록임을 표시하고, 마지막 기록을 현재 적용값으로 단정하지 않는다. 2025년 11월 기록은 월까지만 표시하고 ‘일자 미확인’을 명시한다. 기존 자료의 날짜·값·확인일을 임의로 갱신하지 않는다.

외국어 가이드, 신규 수집·배포·의존성은 추가하지 않는다. CSV 변환·그룹화 및 실제 가이드 경로에서의 노출, 모바일 배치와 전체 웹 테스트·빌드를 확인한다.

## 사용자 요청에 따른 재조사·정확도 보완

사용자가 구조 정리는 직접 하기로 했고, 이번 후속 범위는 변경 이력 재조사와 출처 최대 3개 표시다. 조사 결과와 충돌 판정은 `docs/base-rate-history-research-2026-11-16.md`에 기록한다.

앞의 직전 기록 추론 방식은 폐기한다. 이력에 빈 구간이 있으므로 `previous_rate`도 보도에서 확인한 값을 저장한다. 기존 CSV를 `operator,effective_date,previous_rate,rate,status,source_names,source_urls,note`로 갱신하고, 출처의 이름·URL은 같은 순서의 `|` 구분 목록으로 기록한다. `BaseRateChange.sources`는 `{ name, url }[]`, `note`는 기록별 근거 한계다.

신라·롯데의 2025년 11월 적용일을 보완하고, 신세계는 월까지만 보존하며 현대의 근거 부족 행은 제외한다. 새로 확인한 2024년 12월 이력과 2025년 6월 업계 단위 회고도 추가한다. 업체별 시행 여부가 불확실한 회고는 `industry`로 구분한다. 출처의 매체명을 링크로 최대 3개 표시하고, 적용일과 변경 금액의 근거 범위가 다른 경우 주석을 남긴다. 실제 재조사를 했으므로 마지막 확인일은 2026-11-16으로 갱신하되 현재 값의 보증으로 표현하지 않는다.

## 사용자 지정 표 구조·기사 발췌

같은 월과 같은 변경 전후 값을 하나의 사건 행으로 묶는다. 첫 열에는 변경 값을 굵게, 변경 연월을 작게 표시한다. 다음 열에는 면세점별 적용일을 보존하고, 마지막 열에는 사건별 출처를 중복 없이 합쳐 최대 3개 표시한다. 같은 값이라도 연월이 다른 사건은 분리한다.

2026년 9월·7월·3월 출처는 유지한다. 8월은 서울경제만 유지한다. 2025년 11월은 한 행에 합치되 신세계는 인상 확인·일자 미상, 현대는 인상 여부와 일자 미확인으로 구별한다. 2025년 6월은 변경 사실은 확인된 업계 기록이며 개별 업체·일자를 만들어 넣지 않는다. 2024년 12월의 업체별 날짜도 같은 행에 보존한다.

출처 버튼은 페이지 안의 네이티브 모달 `dialog`를 연다. 매체명·변경 연월·기사 발행일, 기사 본문의 짧은 직접 발췌와 그 아래 원문 링크를 표시한다. 닫기 버튼·Esc·바깥 클릭을 지원하고 포커스 이동은 브라우저의 모달 동작을 따른다. 여러 부분을 발췌하면 각각 별도로 표시한다. 인용은 기사당 전체 합계 25어절 이하로 제한하며, 같은 기사가 다른 사건에도 쓰이면 합산한다. `data/base_rate_excerpts.json`에 출처 URL·발행일·사건별 발췌만 저장한다.

## 차트와 상세 표 위치

사용자 요청에 따라 기준환율 설명 아래의 표를 가이드 본문 맨 아래로 옮기고, 기존 자리에는 차트만 표시한다. 기존 상세 표의 날짜·출처·발췌 상자는 유지한다. 새 차트는 기존 SVG 방식으로 확인된 변경 사건 일곱 개를 과거부터 계단형으로 표시하며, 가로축은 `2026.09.`처럼 월까지만 쓴다. 변경 사건별 간격은 동일하고 기간의 길이를 나타내지 않으며, 이 점은 차트 접근성 설명에 명시한다. 월까지만 확인된 자료에 정확한 적용일을 만들지 않는다. 가로축 글자는 SVG 밖의 반응형 열에 맞춘다. 좁은 화면에서는 글자를 더 줄이는 대신 월 라벨을 두 줄로 번갈아 배치한다.

## 하단 변경 이력 접기·메인 차트 스타일

사용자 후속 요청에 따라 하단 변경 이력은 네이티브 `details`·`summary`로 기본 접힘 처리한다. ‘변경 이력 자세히 보기’를 펼치면 기존 상세 표와 출처 기능이 나타난다. 가이드 하단 위치는 유지한다.

차트는 메인 `RateChart.tsx`의 시각적 패턴을 따른다. `ink` 색의 1.5px 선, `muted` 색의 최저·최고 축, 박스 없는 상단 금액·월 라벨, 위치에 대응하는 세로선과 점을 사용한다. 상시 점·파란 선·수평 격자는 제거한다. 마우스와 터치로 값을 확인하며 벗어나거나 터치가 끝나면 라벨을 감춘다. 계단형 데이터 표현과 월 단위 가로축은 유지한다.

## 최종 위치·시간축 수정

사용자가 위치와 시간축을 수정했다. 변경 이력 토글은 가이드 맨 아래에서 차트 바로 뒤로 옮긴다. 기본 접힘과 상세 표·출처 상자는 유지하며, 설명 섹션 안에 들어가므로 표 제목은 h3로 맞춘다.

이전의 사건별 등간격 배치는 폐기한다. 변경 연월을 연속 개월 번호로 변환해 실제 개월 간격에 비례하는 x좌표를 사용한다. 현재 사건 간격은 6·5·4·4·1·1개월이다. 월 정밀도 자료에 정확한 적용일은 만들지 않는다. 메인 차트처럼 축 눈금은 시작·중간·마지막 월만 표시한다.

추가 요청에 따라 변경 사건이 없는 달도 모두 마우스·터치로 선택한다. 위치를 가장 가까운 달로 맞추고 해당 월까지 확인된 마지막 변경 값을 보여준다. 세로선·점·hover 라벨은 선택한 달에 맞춘다. 그래프 범위는 첫 변경 월부터 조사 확인 월까지다. 마지막 변경 뒤에는 같은 값을 수평으로 이어 표시하며 실제 변경 이력 행은 추가하지 않는다.

## 확정한 시안: 옅은 면 채움

사용자가 세 PNG 시안 중 2번 ‘옅은 면 채움’을 선택했다. 기존 먹색 선을 파란 계단선으로 바꾸고 아래에 옅은 파란 면을 채운다. 50원 간격의 얇은 수평선과 축 값을 표시하고, 데이터 최저·최고 밖으로 각 25원의 여백을 둔다.

상단 왼쪽에는 조사 확인 월과 최근 기록의 큰 금액·단위를 고정하고, 오른쪽에는 ‘면세점 기준환율 / 국산품’을 표시한다. 현재 자료에서는 2026.11. / 1,350원이며 hover·터치에도 바뀌지 않는다. 선택 월과 금액은 홈 차트처럼 선택 위치 위의 별도 라벨로 표시한다. 라벨·세로선·점은 선택 중에만 표시한다.

그래프 자체 높이는 240px을 유지하며 `ResizeObserver`로 실제 너비를 반영해 모바일에서 글자와 차트가 통째로 축소되지 않게 한다. 월 간 시간 비율, 월별 값 선택, 차트 바로 아래의 기본 접힘 변경 이력과 출처 기능은 유지한다.

모바일 세로 스와이프는 브라우저의 페이지 스크롤을 허용하고 선택 라벨을 감춘다. 탭과 가로 이동으로 월을 선택하며 종료·취소 시 선택을 해제한다. 금액이 50원 간격에서 벗어나면 최댓값 눈금을 추가하고, 유효한 기록이 하나도 없으면 차트 대신 안내 문구를 표시한다.
